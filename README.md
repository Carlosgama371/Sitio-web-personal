# Portafolio de Carlos Díaz Gama

Primera versión del rediseño. El sitio estático vive en `dist/` y funciona sin instalación ni compilación.

## Vista previa

Abre `dist/index.html` en el navegador o ejecuta desde la raíz:

```sh
python3 -m http.server 8000 --directory dist
```

Visita http://localhost:8000/. En escritorio y móvil, comprueba el acceso a las secciones, las fichas originales y el recorrido hasta Instagram. Usa Tab y Enter para recorrer los enlaces.

## Pendientes de contenido

- Confirmar el correo comercial o número de WhatsApp. El contacto de esta versión es Instagram.
- Seleccionar y verificar una pieza de video publicitario para publicarla como proyecto.
- Confirmar fechas, alcance y entregables de los proyectos si se quiere ampliar las fichas.

El rediseño se entrega para revisión local, sin despliegue.
